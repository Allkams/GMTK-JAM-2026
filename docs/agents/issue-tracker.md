# Issue tracker: none

This repo (a GMTK Game Jam 2026 project) does not track work in an issue tracker. There are no GitHub issues, `.scratch/` files, or triage labels to read or write.

## When a skill says "publish to the issue tracker"

Don't create an issue anywhere. Present the content (spec, tickets, findings) directly in the conversation instead, and let the user decide whether to save it.

## When a skill says "fetch the relevant ticket"

There is no ticket. Ask the user to describe the work, or use what they've already said in the conversation.

## Triage and wayfinding

`/triage` and `/wayfinder` depend on an issue tracker and don't apply here. Re-run `/setup-matt-pocock-skills` if this repo starts tracking issues.
